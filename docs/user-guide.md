# 簡譜工房使用手冊

適用 0.3.0。這份手冊以 Windows 與二胡單旋律寫譜為例；先學會新增、修改、儲存，就能完成一份可列印的簡譜。

## 安裝、更新與第一次開啟

### 安裝

到[官方下載頁](https://github.com/miles990/jianpu-studio/releases/latest)下載 `JianpuStudio-0.3.0-Windows-x64-Setup.exe`，開啟後選擇繁體中文。可選「為所有使用者安裝」並同意管理員授權，再選 C、D、E 等磁碟或自訂資料夾。只安裝到自己的資料夾時，也可選「僅為我安裝」。支援中文及含空白的路徑。

適用 Windows 10 1903 以上／Windows 11 x64。建議 8 GB RAM、2 GB 可用空間；照片辨識建議 16 GB RAM。所需環境已內附，不用另外安裝 Python、Java、LilyPond 或 Audiveris。下載好安裝檔後，安裝與寫譜不需要網路。第一次試聽或產生列印輸出時，可能需要建立字型快取，請稍等。

免安裝版須完整解壓縮；`JianpuStudio.exe`、`_internal` 與 `runtime` 要留在同一資料夾。勿直接從 ZIP 壓縮檔視窗執行。

### 更新

0.2.1 起的安裝版可直接更新：

1. 選「說明 → 檢查更新」，連線查詢本專案的正式版本及更新說明。
2. 按「下載更新」。程式會核對下載大小與 SHA-256；下載時可取消，取消不會變更已安裝的程式。
3. 核對成功後按「關閉並更新」。若樂譜尚未儲存，先依提示處理。
4. 安裝程式沿用原安裝模式及資料夾，保留設定與自己的樂譜，更新完成後重新開啟。Program Files 等位置需要 Windows 管理員授權。

0.1.2 或更早版本，請先儲存並關閉程式，再執行新版安裝檔，選相同模式與原資料夾。不用先解除安裝，這次升級後就能使用程式內更新。免安裝版可查詢新版，但需從下載頁下載並完整解壓縮新版。

### 認識畫面：同一張譜可讀也可改

預設開啟「編輯樂譜」：中央是一張按小節排列的簡譜，可閱讀，也可直接點音符選取、輸入或修改。上方有新建、開啟、儲存與匯出／列印；曲名、調號、拍號、速度及常用音符工具在譜面上方。開啟既有 `.jps` 或範例時預設為「修改音符」，點選音符後就能調整；新建空譜則先使用「新增音符」。

上方可切換「編輯樂譜」或「原圖對照」。平常直接在主譜面讀寫，照片辨識後才開原圖對照。開啟或編輯樂譜不會先產生 PDF；要列印或輸出 PDF 時，再從「匯出 / 列印」操作。小視窗的編輯工具區可捲動。

主譜面是可編輯的樂譜顯示；需要列印時才產生的 PDF 是正式輸出。兩者的分頁、換行與符號位置可能不同，PDF 本身不能直接編輯。譜面上方的百分比只調整編輯畫面大小，列印字體請用「紙張與排版」。

## 寫一首簡單樂曲

1. 按「新建」，填曲名、作曲者／來源、調號、拍號與速度。
2. 按「＋新增小節」加一個空白小節，程式會自動切到「填寫小節」。要先準備整首曲子的空位，可從小節選單一次新增多個。
3. 將時值選為四分音符，點要填寫的休止符，用滑鼠點 `1–7` 或在譜面按數字鍵。4/4 拍輸入 `1 2 3 4`，就完成一小節；`0` 輸入休止符。
4. 要修改，切到「修改音符」，在同一張譜面點選音符，再用譜面上方工具調整音高、時值、八度、升降或附點，改動會直接套用。
5. 要增加樂段，先選好小節，再按「＋新增小節」或使用小節選單；新小節會有完整拍數的休止符可供填寫。
6. 按 `Ctrl+S` 儲存 `.jps` 專案，下次用「開啟」繼續編輯。

### 三種輸入方式

| 模式 | 適合的操作 | 對後面音樂的影響 |
| --- | --- | --- |
| 填寫小節 | 在休止符空位寫入下一個音符；新增或清空小節後會自動使用 | 消耗可用休止時值，保留後面小節的位置，不覆蓋已寫好的音符；空間不夠會提示 |
| 新增音符 | 逐音建立樂譜，可選「插在選取後」「插在選取前」或「加到曲尾」 | 插入音符會增加時值，後面音符會往後移並重新分小節 |
| 修改音符 | 改所選音符的音高、時值、八度、升降、附點或記號 | 改音高不影響節奏；改時值仍會重新分小節，並非固定小節內的節奏改寫 |

填寫只能使用同一小節內的連續休止空位，不能跨過已寫好的音符。切換回填寫時，可從模式下拉選單選「填寫小節」。

「填寫小節」及「新增音符」的譜面上方設定用於下一個音符；「修改音符」才會直接套用到選取內容。填寫時先選休止符，若該處沒有足夠空位，可縮短下一音符、清空要重寫的小節，或新增小節。

逐音新增後，最後一小節不足時可按「補齊休止符」。提示音符超出小節時，按「定位問題」檢查並縮短時值；跨小節長音可拆成相同音高的音符，再加延音線。

以四分音符為一拍，八分音符是半拍、十六分是四分之一拍。八分音符下方有一條減時線、十六分有兩條、三十二分有三條；高八度的點在上方，低八度在下方。6/8 拍每小節合計六個八分音符，也就是三個四分音符的長度。

歌詞可填在下方「歌詞」欄；二胡純器樂可留白。勾選「五線譜對照」會在正式排版中一併顯示五線譜。

## 新增、清空、刪除與重複小節

先點小節號或小節中的空白處，選取整個小節；也可選該小節內的音符後按 `M`。需要一段小節時，用 `Shift` 連選。小節工具依目前選取範圍操作；右鍵選單也有入口。

| 操作 | 結果 |
| --- | --- |
| ＋新增小節 | 在所選小節之後插入一個空白小節 |
| 前插／曲尾新增 | 從小節選單選擇在所選之前插入，或加在整首曲子的最後 |
| 新增多個小節… | 按「＋新增小節」旁的箭頭，再選「新增多個小節…」，指定數量及插入位置 |
| 清空小節 | 移除選定小節的內容，換成相同小節長度的休止符；節數及後面小節的位置保留 |
| 刪除小節 | 移除選定的小節，後面小節往前移，整首樂曲縮短 |
| 重複小節 | 將完整的所選小節範圍複製一份，插在該段之後 |

例如原有第 1–4 小節：清空第 2 小節後，第 3 小節仍是第 3 小節；刪除第 2 小節後，原第 3 小節會成為第 2 小節。只想重寫旋律時用「清空小節」，想縮短樂曲時才用「刪除小節」。

若最後一小節尚未寫滿，從曲尾新增、重複包含尾節的範圍，會先補足尾節；清空尾節也會留下完整小節的休止符。重複小節需選連續範圍；原譜若有跨小節音符或不完整連線／反覆，請先依提示修正，再使用小節工具。

新增與清空後會自動切到「填寫小節」，可直接填入休止空位。所有小節操作都可用 `Ctrl+Z` 復原、`Ctrl+Y` 重做，包含選取範圍。若改動切斷連弓、延音或反覆，程式會清理受影響的成對記號並提示；未受影響的記號會保留。復原也會還原記號。

## 選取、複製與一起修改

- 點一下選取單一音符；按住 `Shift` 再點另一個音符可連選一段，按住 `Ctrl` 點選可加入或取消個別音符。
- 在音符區按 `Ctrl+A` 全選，按 `Esc` 取消選取；按 `M` 選取目前音符所在的小節，或點小節號／空白處。
- 切到「修改音符」後，多個音符的屬性不一致時會顯示「不同」，附點會顯示混合狀態。只改時值，就只改時值，各音符原本的音高、八度及其他屬性會保留。
- 按 `Ctrl+C` 複製，`Ctrl+X` 剪下，`Ctrl+V` 貼上；貼上依目前的「插在選取前／後／曲尾」位置放入。要調整貼上位置，先切回「新增音符」。
- 按 `Ctrl+D` 重複所選音符，也會依插入位置放入。複製或重複會保留音符上的演奏記號；連線或反覆須連同完整範圍選取，貼上後再檢查。
- 按 `Delete` 刪除；`Ctrl+Z` 復原，`Ctrl+Y` 重做，會一併還原當時的選取範圍。

音符貼上目前接受本程式複製的音符。一般簡譜文字可貼到「進階語法」編輯區，不能直接貼成視覺音符。小節跳轉可使用上方「小節」欄，或在音符區按 `Alt+← / →`。

## 二胡指法與演奏記號

切到「修改音符」，選好音符，按「二胡 / 記號」。把要改的項目選好，再按確定；其他項目選「保持原樣」，即可保留各音符的差異。選「無」會移除該項記號。

| 項目 | 可選內容 |
| --- | --- |
| 指法 | 空弦 0、1–4 指 |
| 弓法 | 推弓 ∨、拉弓 Π |
| 力度 | pp、p、mp、mf、f、ff、sfz |
| 演奏法 | 跳音、保持音、重音、延長、顫音、波音 |
| 滑音 | 上滑音、下滑音 |
| 連弓線 | 至少選取兩個連續音符，選「加入所選範圍」 |
| 延音線 | 選取連續、相同音高的音符，選「加入所選範圍」；八度及升降也必須相同 |
| 反覆段落 | 選取連續的完整小節，再選「加入所選範圍」 |

在「新增音符」或「填寫小節」模式開啟此視窗，會設定下一個音符的指法、弓法、力度、演奏法及滑音。連弓線、延音線與反覆段落請在修改模式選取範圍後設定。

連線與反覆可選「移除所選記號」清除。連弓線不能重疊，反覆段落不能重疊，反覆起點與終點要位於完整小節邊界。指法、弓法、滑音與連線不適用於休止符；把音符改成休止符時，這些記號會自動移除。

這些記號可用於譜面及列印。試聽使用 Windows MIDI 合成器，音色取決於系統，無法重現真實二胡的弓法、指法與滑音。

## 試聽、PDF 與列印

### 平常讀寫不用 PDF

主譜面會隨編輯立即更新，直接在上面閱讀、點選與修改即可。開啟、輸入或修改樂譜不會在背景先產生 PDF。小節拍數或記號有問題時，譜面會提示，先修正再試聽或輸出。

### 試聽

按上方「試聽」或在譜面按 `Enter`，再按一次停止。程式會準備目前樂譜的 MIDI 再播放，不需要先產生或開啟 PDF；編輯音符會停止舊的試聽。

若進階原始碼包含多樂章（`NextScore`），內建試聽及 MIDI 匯出目前使用第一樂章的主 MIDI。要分別匯出其他樂章，請將各樂章另存為獨立專案。

### 紙張與大小

按「紙張與排版」，可選 A4 或 Letter，譜字大小可調 16–30，每行小節數可選自動或 1–8。紙張與譜字大小會用於正式 PDF；固定每行小節數用於視覺樂譜轉出的簡譜。進階語法的換行請自行在原始碼調整。

編輯區的 75%–200% 縮放只影響畫面顯示，不改變列印尺寸。

### 列印預覽與匯出 PDF

1. 要確認列印效果，選「匯出 / 列印 → 列印預覽」或按 `F5`，程式才產生正式 PDF。
2. 在預覽中檢查換行、分頁與記號，可縮放及閱讀多頁；看完按「返回樂譜」繼續編輯。
3. 要保存 PDF，直接選「匯出 / 列印 → PDF 樂譜」。程式會準備最新排版並讓您選位置保存，不必先按 F5。
4. 要列印，選「匯出 / 列印 → 開啟 PDF / 列印」，或在預覽內按「開啟列印」，由 Windows 預設 PDF 閱讀器開啟，再使用閱讀器的列印功能。預覽內也可按「匯出 PDF」保存。

「匯出 / 列印」也可保存 MIDI、簡譜 `.jly` 與 LilyPond `.ly`。正式 PDF 使用目前樂譜內容；主譜面與 PDF 的分頁、換行可能不同，列印前請用預覽確認。多樂章的 PDF 會包含各樂章。

## 照片轉簡譜

1. 準備清楚的印刷五線譜照片，建議 300 DPI 掃描，或在明亮均勻環境拍照。
2. 按「照片辨識」，選 PNG、JPEG、TIFF 或 BMP。
3. 用 90° 旋轉、微調角度、裁白邊與增強對比整理；不要裁掉譜號、調號或小節線。
4. 按「開始辨識」，過程可取消。若引擎回報譜線間距太小，程式會依量測結果自動放大 2–4 倍並重試一次；放大後不超過 4,000 萬像素。
5. 完成後切到「原圖對照」，用「＋」「−」或「符合寬度」對照。逐小節檢查音高、調號、拍號與節奏；簡單單聲部可直接選取音符修改，複雜譜面可能進入進階模式。
6. 儲存 `.jps`。需要辨識的中間成果時，用「匯出 / 列印 → 辨識結果 MusicXML」匯出；原照片請自行保留。

自動重試自 0.1.2 起提供。放大無法補回模糊或遺失的細節，辨識後仍須人工校對。軟體不支援手寫譜或數字簡譜照片，中文歌詞需手動補入。混有和弦圖或其他版面元素的照片可能需要更多校對。

辨識失敗時先看中文原因；可換清晰原圖再試，或使用「工具 → 開啟 Audiveris 校對工具」，完成後從「檔案 → 匯入 MusicXML」匯入。需要回報問題時，選「工具 → 作業訊息」，按「複製完整紀錄」。

## 匯入與進階語法

### 匯入現有樂譜

「檔案 → 匯入 MusicXML」接受 MusicXML／MXL。簡單單旋律可進入視覺編輯，複雜內容可能保留為進階原始碼。不能直接開啟 EOPN；若其他軟體可匯出 MusicXML，可先匯出後再嘗試匯入，並檢查結果。

### 弱起、三連音、倚音與多聲部

這些功能目前需要「進階語法」，尚無完整滑鼠編輯流程。先完成視覺草稿的小節，按「進階語法」，會將樂譜轉為文字。按「插入常用語法…」可在游標處插入三連音、前／後倚音、弱起拍號、反覆、連弓線、換行及另一聲部的範例。

弱起拍號範例要**取代原拍號**，不能只加在旁邊。多聲部範例要自行補齊各聲部相同的長度。插入範例後仍需檢查音符與小節拍數；需要列印時再確認 PDF。

以下是兩個完整 4/4 小節的簡單範例：

```text
title=練習曲
NoIndent
```

`c1` 是四分音符，`q1` 是八分，`s1` 是十六分；`1'` 高八度，`1,` 低八度，`#1` 升音，`b3` 降音。`H:` 可接中文字歌詞，`NextPart` 分聲部，`WithStaff` 同時顯示五線譜。完整語法請見 [jianpu-ly 文件](https://github.com/ssb22/jianpu-ly)。

「返回視覺草稿」使用切換前的視覺內容，**不會把進階原始碼自動轉回音符**；程式會先確認，原始碼仍保留在專案內。再次進入時，可選擇繼續舊原始碼，或用視覺草稿重新產生。

部分原始 LilyPond／Scheme 指令（例如 `LP:`、`LPH:`、`chords=`、`frets=`）受限制。需要完整原始 LilyPond 功能時，請使用獨立工具。

## 儲存與復原

`.jps` 是可繼續編輯的專案；PDF 適合列印與分享，MIDI 適合播放。請用「儲存」保留專案，不要只匯出 PDF。

程式每 15 秒在本機使用者資料夾建立復原暫存；意外中斷後，下次啟動會詢問是否復原。它不是歷史版本備份，重要作品請定期另存及備份。開啟其他專案、離開或套用更新前，未儲存變更會先詢問。

請一次開啟一個程式實例，避免兩個視窗覆蓋同一份復原檔。

## 常見問題

| 情況 | 處理 |
| --- | --- |
| 按數字鍵沒有輸入音符 | 先點譜面；確認目前是填寫、新增或修改模式。曲名、歌詞與原始碼欄位會接收文字輸入。 |
| 調整時值卻沒改到已選音符 | 切到「修改音符」。新增與填寫模式只設定下一個音符。 |
| 填寫時提示休止空間不足 | 選休止符，縮短下一音符，或先清空／新增小節；填寫模式不會擠動後面小節或覆蓋已寫好的音符。 |
| 想在 PDF 上改音符 | 返回「編輯樂譜」點選音符；列印預覽中的 PDF 唯讀。 |
| 想看列印結果 | 按 F5 或「匯出 / 列印 → 列印預覽」。PDF 按需產生，平常讀寫不需要開啟。 |
| PDF 無法產生 | 確認小節拍數及連線／反覆完整，選「工具 → 作業訊息」查看原因後重試。 |
| 照片辨識失敗 | 查看中文原因；譜線太小時會自動重試一次，仍失敗請換清晰原圖。可複製完整紀錄回報。 |
| 不能試聽 | 等音樂準備完成，確認 Windows 音訊裝置可用；亦可匯出 MIDI，不需要先產生 PDF。 |
| 更新下載失敗 | 確認網路及磁碟空間，重新檢查；也可從官方下載頁取得安裝檔。 |
| 安裝錯誤 5：存取被拒 | 取消並重開安裝，選「僅為我安裝」及預設個人路徑；安裝到 Program Files 請選「為所有使用者安裝」。 |
| 找不到排譜／辨識工具 | 重裝完整安裝版；免安裝版請確認完整解壓縮，沒有移走 runtime 等資料夾。 |
| 安裝檔顯示未知發行者 | 目前安裝檔尚未簽章；確認來自官方下載頁，可用 SHA256SUMS.txt 核對。 |
| 想移除程式 | Windows 設定 → 應用程式 → 簡譜工房 → 解除安裝；自己的樂譜不會被刪除。 |

到[問題回報](https://github.com/miles990/jianpu-studio/issues)附上 Windows 版本、程式版本、操作步驟及完整紀錄。照片或樂譜含私人內容時，請先製作可以公開的重現範例。
