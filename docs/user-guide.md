# 簡譜工房使用手冊

適用 0.2.1。這份手冊以 Windows 與二胡單旋律寫譜為例；先學會新增、修改、儲存，就能完成一份可列印的簡譜。

## 安裝、更新與第一次開啟

### 安裝

到[官方下載頁](https://github.com/miles990/jianpu-studio/releases/latest)下載 `JianpuStudio-0.2.1-Windows-x64-Setup.exe`，開啟後選擇繁體中文。可選「為所有使用者安裝」並同意管理員授權，再選 C、D、E 等磁碟或自訂資料夾。只安裝到自己的資料夾時，也可選「僅為我安裝」。支援中文及含空白的路徑。

適用 Windows 10 1903 以上／Windows 11 x64。建議 8 GB RAM、2 GB 可用空間；照片辨識建議 16 GB RAM。所需環境已內附，不用另外安裝 Python、Java、LilyPond 或 Audiveris。下載好安裝檔後，安裝與寫譜不需要網路。第一次排譜可能需要建立字型快取，請稍等。

免安裝版須完整解壓縮；`JianpuStudio.exe`、`_internal` 與 `runtime` 要留在同一資料夾。勿直接從 ZIP 壓縮檔視窗執行。

### 更新

0.2.1 起的安裝版可直接更新：

1. 選「說明 → 檢查更新」，連線查詢本專案的正式版本及更新說明。
2. 按「下載更新」。程式會核對下載大小與 SHA-256；下載時可取消，取消不會變更已安裝的程式。
3. 核對成功後按「關閉並更新」。若樂譜尚未儲存，先依提示處理。
4. 安裝程式沿用原安裝模式及資料夾，保留設定與自己的樂譜，更新完成後重新開啟。Program Files 等位置需要 Windows 管理員授權。

0.1.2 或更早版本，請先儲存並關閉程式，再執行新版安裝檔，選相同模式與原資料夾。不用先解除安裝，這次升級後就能使用程式內更新。免安裝版可查詢新版，但需從下載頁下載並完整解壓縮新版。

### 認識畫面

上方有「新建」「開啟」「照片辨識」「復原」「重做」「儲存」及「匯出 / 列印」。左邊是按小節排列的音符編輯區，右邊是正式 PDF、原圖校對與作業訊息。

左下角可選「編輯與預覽」「專心編輯」「閱讀預覽」或「原圖校對」。小螢幕可切換單一區域，編輯區也能捲動。音符區上方的百分比只調整編輯畫面大小；列印字體請用「紙張與排版」。

## 寫一首簡單樂曲

1. 按「新建」，填曲名、作曲者／來源、調號、拍號與速度。
2. 保持「新增音符」，將時值選為四分音符。用滑鼠點 `1–7` 加入音符，`0` 加入休止符；點音符區後也能按數字鍵。
3. 例如在 4/4 拍輸入 `1 2 3 4`，就完成一小節。下方會提示拍數是否完整。
4. 要修改時，切換「修改音符」，選取音符，再調整下方的音高、時值、八度、升降或附點。調整會直接套用，不需要再按套用按鈕。
5. 要繼續新增，切回「新增音符」，選「插在選取後」「插在選取前」或「加到曲尾」。沒有選取時會加在曲尾。
6. 最後一小節不足時按「補齊休止符」。畫面提示音符超出小節時，按「定位問題」檢查並縮短時值；跨小節長音可拆成相同音高的音符，再加延音線。
7. 按 `Ctrl+S` 儲存 `.jps` 專案。它保留可編輯的樂譜，下次用「開啟」繼續。

「新增音符」下方設定用於下一個新音符，不會改動已選音符；「修改音符」才會改動選取內容。可在音符區按空白鍵切換，請留意上方顯示的模式。

以四分音符為一拍，八分音符是半拍、十六分是四分之一拍。八分音符下方有一條減時線、十六分有兩條、三十二分有三條；高八度的點在上方，低八度在下方。6/8 拍每小節合計六個八分音符，也就是三個四分音符的長度。

歌詞可填在下方「歌詞」欄；二胡純器樂可留白。勾選「五線譜對照」會在正式排版中一併顯示五線譜。

## 選取、複製與一起修改

- 點一下選取單一音符；按住 `Shift` 再點另一個音符可連選一段，按住 `Ctrl` 點選可加入或取消個別音符。
- 在音符區按 `Ctrl+A` 全選，按 `Esc` 取消選取；按 `M` 選取目前音符所在的小節，或雙擊該小節。
- 切到「修改音符」後，多個音符的屬性不一致時會顯示「不同」，附點會顯示混合狀態。只改時值，就只改時值，各音符原本的音高、八度及其他屬性會保留。
- 按 `Ctrl+C` 複製，`Ctrl+X` 剪下，`Ctrl+V` 貼上；貼上依目前的「插在選取前／後／曲尾」位置放入。要調整貼上位置，先切回「新增音符」。
- 按 `Ctrl+D` 重複所選音符，也會依插入位置放入。複製或重複會保留音符上的演奏記號；連線或反覆須連同完整範圍選取，貼上後再檢查。
- 按 `Delete` 刪除；`Ctrl+Z` 復原，`Ctrl+Y` 重做，會一併還原當時的選取範圍。

音符貼上目前接受本程式複製的音符。一般簡譜文字可貼到「進階語法」編輯區，不能直接貼成視覺音符。小節跳轉可使用上方「小節」欄，或在音符區按 `Alt+← / →`。

## 二胡指法與演奏記號

切到「修改音符」，選好音符，按「二胡 / 記號」。把要改的項目選好，再按確定；其他項目選「保持原樣」，即可保留各音符的差異。選「無」會移除該項記號。

| 項目 | 可選內容 |
| --- | --- |
| 指法 | 空弦 0、1–4 指 |
| 弓法 | 推弓 ∨、拉弓 Π |
| 力度 | pp、p、mp、mf、f、ff、sfz |
| 演奏法 | 跳音、保持音、重音、延長、顫音、波音 |
| 滑音 | 上滑音、下滑音 |
| 連弓線 | 至少選取兩個連續音符，選「加入所選範圍」 |
| 延音線 | 選取連續、相同音高的音符，選「加入所選範圍」；八度及升降也必須相同 |
| 反覆段落 | 選取連續的完整小節，再選「加入所選範圍」 |

在「新增音符」模式開啟此視窗，會設定下一個音符的指法、弓法、力度、演奏法及滑音。連弓線、延音線與反覆段落請在修改模式選取範圍後設定。

連線與反覆可選「移除所選記號」清除。連弓線不能重疊，反覆段落不能重疊，反覆起點與終點要位於完整小節邊界。指法、弓法、滑音與連線不適用於休止符；把音符改成休止符時，這些記號會自動移除。

這些記號可用於譜面及列印。試聽使用 Windows MIDI 合成器，音色取決於系統，無法重現真實二胡的弓法、指法與滑音。

## 快捷鍵

先點音符區，再使用下表的音符操作。輸入曲名、歌詞或進階原始碼時，鍵盤會依該文字欄位操作。用過 EOP 可沿用部分輸入習慣，但不是全部快捷鍵都相同，也不能直接開啟 EOPN 檔案。

| 按鍵 | 音符區內的操作 |
| --- | --- |
| `0–7` | 新增模式輸入休止／音符；修改模式改所選音符的音高 |
| `Space` 空白鍵 | 切換新增／修改 |
| `Enter` | 試聽／停止 |
| `Q / W / E / R / A / S` | 全／二分／四分／八分／十六分／三十二分音符 |
| `↑ / ↓` | 升／降八度 |
| `[ / ]` | 縮短／延長時值 |
| `.` | 切換附點 |
| `Shift` 點選／`Ctrl` 點選 | 連選／加選音符 |
| `Ctrl+A`／`Esc` | 全選／取消選取 |
| `M` | 選取目前小節 |
| `Alt+← / →` | 前／後一小節 |
| `Ctrl+C / X / V` | 複製／剪下／貼上 |
| `Ctrl+D` | 重複所選音符 |
| `Delete` 或 `Backspace` | 刪除所選音符 |

時值、八度與附點快捷鍵在新增模式設定下一音符，在修改模式套用到所選音符。

| 按鍵 | 一般操作 |
| --- | --- |
| `Ctrl+N`／`Ctrl+O` | 新建／開啟 |
| `Ctrl+S`／`Ctrl+Shift+S` | 儲存／另存新檔 |
| `Ctrl+Z`／`Ctrl+Y` | 復原／重做 |
| `F5` | 更新正式 PDF 排版 |
| `Ctrl+E` | 匯出 PDF |
| `F1` | 快速操作說明 |

## 排版、試聽與列印

### 更新正式排版

右側「正式排版」是實際產生的 PDF，可縮放及閱讀多頁。勾選「自動」時，停止編輯後會排版；也可按「更新」或 `F5`。排版進行中仍可編輯，完成後會繼續處理新變更。小節拍數或記號不完整時，先依下方提示修正，再更新。

### 紙張與大小

按「紙張與排版」，可選 A4 或 Letter，譜字大小可調 16–30，每行小節數可選自動或 1–8。紙張與譜字大小會用於正式 PDF；固定每行小節數用於視覺草稿轉出的簡譜。進階語法的換行請自行在原始碼調整。

編輯區的 75%–200% 縮放，以及 PDF 的「符合寬度」「＋」「−」，只影響畫面顯示，不改變列印尺寸。

### 試聽與匯出

按「試聽」或在音符區按 `Enter`；再按一次停止。如果樂譜已改動，會先更新排版，成功後播放。編輯音符會停止舊的試聽。

「匯出 / 列印」可匯出 PDF、MIDI、簡譜 `.jly` 與 LilyPond `.ly`。要列印，選「開啟 PDF / 列印」，由 Windows 預設 PDF 閱讀器開啟，再使用閱讀器的列印功能。內容改變後要先完成新排版，才能匯出或開啟最新 PDF／MIDI。

若進階原始碼包含多樂章（`NextScore`），PDF 會包含各樂章，內建試聽及 MIDI 匯出目前使用第一樂章的主 MIDI。要分別匯出其他樂章，請將各樂章另存為獨立專案。

## 照片轉簡譜

1. 準備清楚的印刷五線譜照片，建議 300 DPI 掃描，或在明亮均勻環境拍照。
2. 按「照片辨識」，選 PNG、JPEG、TIFF 或 BMP。
3. 用 90° 旋轉、微調角度、裁白邊與增強對比整理；不要裁掉譜號、調號或小節線。
4. 按「開始辨識」，過程可取消。若引擎回報譜線間距太小，程式會依量測結果自動放大 2–4 倍並重試一次；放大後不超過 4,000 萬像素。
5. 完成後切到「原圖校對」，用「＋」「−」或「符合寬度」對照。逐小節檢查音高、調號、拍號與節奏；簡單單聲部可直接選取音符修改，複雜譜面可能進入進階模式。
6. 儲存 `.jps`。需要辨識的中間成果時，用「匯出 / 列印 → 辨識結果 MusicXML」匯出；原照片請自行保留。

自動重試自 0.1.2 起提供。放大無法補回模糊或遺失的細節，辨識後仍須人工校對。軟體不支援手寫譜或數字簡譜照片，中文歌詞需手動補入。混有和弦圖或其他版面元素的照片可能需要更多校對。

辨識失敗時先看中文原因；可換清晰原圖再試，或使用「工具 → 開啟 Audiveris 校對工具」，完成後從「檔案 → 匯入 MusicXML」匯入。需要回報問題時，在「作業訊息」按「複製完整紀錄」。

## 匯入與進階語法

### 匯入現有樂譜

「檔案 → 匯入 MusicXML」接受 MusicXML／MXL。簡單單旋律可進入視覺編輯，複雜內容可能保留為進階原始碼。不能直接開啟 EOPN；若其他軟體可匯出 MusicXML，可先匯出後再嘗試匯入，並檢查結果。

### 弱起、三連音、倚音與多聲部

這些功能目前需要「進階語法」，尚無完整滑鼠編輯流程。先完成視覺草稿的小節，按「進階語法」，會將樂譜轉為文字。按「插入常用語法…」可在游標處插入三連音、前／後倚音、弱起拍號、反覆、連弓線、換行及另一聲部的範例。

弱起拍號範例要**取代原拍號**，不能只加在旁邊。多聲部範例要自行補齊各聲部相同的長度。插入範例後仍需檢查音符、小節拍數與正式 PDF。

以下是兩個完整 4/4 小節的簡單範例：

```text
title=練習曲
NoIndent
1=C 4/4 4=96
c1 c2 c3 c4
q5 q6 c5 c0 c0
```

`c1` 是四分音符，`q1` 是八分，`s1` 是十六分；`1'` 高八度，`1,` 低八度，`#1` 升音，`b3` 降音。`H:` 可接中文字歌詞，`NextPart` 分聲部，`WithStaff` 同時顯示五線譜。完整語法請見 [jianpu-ly 文件](https://github.com/ssb22/jianpu-ly)。

「返回視覺草稿」使用切換前的視覺內容，**不會把進階原始碼自動轉回音符**；程式會先確認，原始碼仍保留在專案內。再次進入時，可選擇繼續舊原始碼，或用視覺草稿重新產生。

部分原始 LilyPond／Scheme 指令（例如 `LP:`、`LPH:`、`chords=`、`frets=`）受限制。需要完整原始 LilyPond 功能時，請使用獨立工具。

## 儲存與復原

`.jps` 是可繼續編輯的專案；PDF 適合列印與分享，MIDI 適合播放。請用「儲存」保留專案，不要只匯出 PDF。

程式每 15 秒在本機使用者資料夾建立復原暫存；意外中斷後，下次啟動會詢問是否復原。它不是歷史版本備份，重要作品請定期另存及備份。開啟其他專案、離開或套用更新前，未儲存變更會先詢問。

請一次開啟一個程式實例，避免兩個視窗覆蓋同一份復原檔。

## 常見問題

| 情況 | 處理 |
| --- | --- |
| 按數字鍵沒有輸入音符 | 先點音符區；確認目前是新增或修改模式。曲名、歌詞與原始碼欄位會接收文字輸入。 |
| 調整時值卻沒改到已選音符 | 切到「修改音符」。新增模式只設定下一個音符。 |
| 排版沒有更新 | 確認小節拍數及連線／反覆完整，按 F5；查看「作業訊息」。 |
| 照片辨識失敗 | 查看中文原因；譜線太小時會自動重試一次，仍失敗請換清晰原圖。可複製完整紀錄回報。 |
| 不能試聽 | 等排版完成，確認 Windows 音訊裝置可用；亦可匯出 MIDI。 |
| 更新下載失敗 | 確認網路及磁碟空間，重新檢查；也可從官方下載頁取得安裝檔。 |
| 安裝錯誤 5：存取被拒 | 取消並重開安裝，選「僅為我安裝」及預設個人路徑；安裝到 Program Files 請選「為所有使用者安裝」。 |
| 找不到排譜／辨識工具 | 重裝完整安裝版；免安裝版請確認完整解壓縮，沒有移走 runtime 等資料夾。 |
| 安裝檔顯示未知發行者 | 目前安裝檔尚未簽章；確認來自官方下載頁，可用 SHA256SUMS.txt 核對。 |
| 想移除程式 | Windows 設定 → 應用程式 → 簡譜工房 → 解除安裝；自己的樂譜不會被刪除。 |

到[問題回報](https://github.com/miles990/jianpu-studio/issues)附上 Windows 版本、程式版本、操作步驟及完整紀錄。照片或樂譜含私人內容時，請先製作可以公開的重現範例。
