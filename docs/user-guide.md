# 簡譜工房使用手冊

## 安裝與第一次開啟

下載 Release 的 `Setup.exe`，雙擊、選擇繁體中文，可選「為所有使用者安裝」並同意管理員授權，再自由選擇 C、D、E 等磁碟或自訂資料夾。只安裝到自己的資料夾時，也可選「僅為我安裝」。桌面捷徑會開啟含「小星星」範例的編輯器。第一次排譜可能需要建立字型快取；請稍等。安裝程式不需要網路，也不會修改全域 PATH。

免安裝版要完整解壓縮，exe、`_internal` 與 `runtime` 必須留在同一資料夾。勿直接在 ZIP 壓縮檔視窗內開啟程式。

### 更新與小視窗

已安裝舊版時，儲存樂譜並關閉程式，執行新版安裝檔，選相同模式與原安裝資料夾即可，不用先移除。0.1.3 起可使用「說明 → 檢查更新 → 下載更新 → 關閉並更新」。更新檔會核對大小與 SHA-256，再沿用原安裝模式與路徑升級並重開。未儲存樂譜會先詢問。取消下載不會變更已安裝的程式。免安裝版請從下載頁取得新版。

視窗寬度不足時會收起側欄；新建、開啟、照片與 MusicXML 匯入可從「檔案」選單操作。編輯區可捲動，較小螢幕也能操作底部控制項。

## 寫一首簡單樂曲

1. 按左側「新建樂譜」，填曲名、作曲者、調號、拍號與速度。
2. 點數字 1–7 加入音符，0 是休止符。預設四分音符為一拍。
3. 點要修改的音符卡片，下方調整音高、時值、八度、升降、附點，再按「套用到選取音符」。這些設定也用於下一個新音符。
4. 新音符插在目前選取的音符後面；沒有選取時加在最後。可用「移前」「移後」「複製」「刪除」整理。
5. 小節號顯示在小節第一個音符上；程式自動累計拍數。最後一小節不滿時按「補齊休止符」。音符跨過小節時，縮短它或改用進階語法的連結線。
6. 停止編輯約一秒後會排版。未滿小節時先顯示修正說明，不會匯出錯誤版本。
7. Ctrl+S 儲存 `.jps` 專案，下一次可繼續編輯。

八分音符是一條減時線、十六分是兩條、三十二分是三條；高八度的點在上方，低八度在下方。以四分音符為一拍計算，6/8 拍每小節合計 3 拍。

## 預覽、列印、試聽

右側是 LilyPond 實際產生的 PDF。可縮放、捲動多頁；「開啟 / 列印」交給 Windows 預設 PDF 閱讀器。PDF 是向量樂譜，放大不失真。

「試聽 / 停止」使用 Windows 內建 MIDI 合成器。變更音符會停止舊試聽；需等新排版完成後再播放。多聲部會使用排譜引擎輸出的 MIDI。音色取決於 Windows MIDI 合成器。

匯出選單支援 PDF、MIDI、簡譜 `.jly`、LilyPond `.ly`。內容改變後不允許匯出舊的 PDF／MIDI；先按更新排版。

若進階原始碼包含多樂章（`NextScore`），PDF 會包含各樂章，內建試聽與 MIDI 匯出目前使用第一樂章的主 MIDI。要分別匯出其他樂章，請將各樂章另存為獨立專案。

## 照片轉簡譜

1. 確認照片是印刷五線譜，字與譜線清楚。建議掃描 300 dpi 或在明亮均勻環境拍照。
2. 按「照片轉簡譜」，選 PNG、JPEG、TIFF 或 BMP。
3. 用 90° 旋轉、微調角度、裁白邊、增強對比整理；不要裁掉譜號、調號或小節線。
4. 按「開始辨識」，通常需 1–5 分鐘；可按取消。若引擎回報譜線間距太小，程式會依量測結果自動放大 2–4 倍並重試一次；放大後不超過 4,000 萬像素。放大不能補回遺失細節，仍需校對。
5. 完成後對照「照片原圖」逐小節校對。簡單單聲部可直接點音符修改；複雜音樂會進入原始碼模式。
6. 儲存 `.jps`。需要中間成果時匯出 MusicXML；原照片請自行保留。

**辨識不等於校對完成。** 軟體不支援手寫或數字簡譜照片，不保證任意照片可辨識。中文歌詞請手動補入。失敗時先嘗試更清楚的照片，或使用「工具 → 開啟 Audiveris 校對工具」處理，再匯入 MusicXML。

## 進階模式

切換進階模式會把目前完整小節轉為 jianpu-ly 原始碼。例如：

```text
title=練習曲
NoIndent
1=C 4/4 4=96
1 2 3 4
q5 q6 5 - 0
```

`1 -` 是二分，`1'` 高八度，`1,` 低八度，`q1` 八分，`s1` 十六分，`#1` 升音，`b3` 降音。`H:` 可接中文字歌詞，`NextPart` 分聲部，`WithStaff` 同時顯示五線譜。完整語法請見上游 jianpu-ly 文件。

返回視覺模式使用原本的視覺草稿，不會把複雜原始碼自動解析成卡片。程式會先確認。原始碼中的 `LP:`、`LPH:`、Scheme、自訂 LilyPond 指令、`chords=`、`frets=` 被限制，以避免讀取檔案時執行程式碼。受信任的完整 LilyPond 應在獨立工具中處理。

## 儲存與復原

每 15 秒在本機使用者資料夾建立復原暫存；意外中斷後，下次啟動會詢問是否復原。它不是歷史版本備份，重要作品請定期另存與備份。正式存檔採寫入暫存檔後替換，降低寫入失敗損壞原檔的風險。

一次開啟一個程式實例，避免兩個視窗覆蓋同一份復原檔。開啟其他專案或離開前，未儲存變更會先詢問。

## 常見問題

| 情況 | 處理 |
| --- | --- |
| 安裝錯誤 5：存取被拒 | 取消並重開安裝，選「只為我安裝」及預設個人路徑；要裝到 Program Files 請選「為所有使用者安裝」。 |
| 找不到 LilyPond / Audiveris | 重裝完整版；免安裝版請保留完整資料夾。開發者可到工具設定指定 exe。 |
| 排版沒有更新 | 先確認每小節拍數；F5 更新；查看右側訊息。 |
| 照片辨識失敗 | 查看中文原因。低解析度會自動重試；仍失敗時使用清晰原圖。按「複製完整紀錄」可取得完整錯誤供回報。 |
| 不能試聽 | 確認 Windows 音訊裝置可用；亦可匯出 MIDI。 |
| 安裝檔顯示未知發行者 | 初版沒有程式碼簽章；核對官方 repo 的 Release 與 SHA-256。企業電腦可能需要管理者核准。 |
| 想移除 | Windows 設定 → 應用程式 → 簡譜工房 → 解除安裝；自己的樂譜不會被刪除。 |

錯誤回報請附 Windows 版本、程式版本、操作步驟、右側訊息；照片或樂譜若含私人／受著作權保護內容，請先做可公開的最小重現檔。
