# 簡譜工房使用手冊

**本手冊適用 0.3.1。** 使用舊版的讀者可參考[0.3.0 手冊](https://github.com/miles990/jianpu-studio/blob/v0.3.0/docs/user-guide.md)。

這份手冊以 Windows 與二胡單旋律寫譜為例；先學會新增、修改、儲存，就能完成一份可列印的簡譜。

## 安裝、更新與第一次開啟

### 安裝

到[官方下載頁](https://github.com/miles990/jianpu-studio/releases/tag/v0.3.1)下載 `JianpuStudio-0.3.1-Windows-x64-Setup.exe`，開啟後選擇繁體中文。可選「為所有使用者安裝」並同意管理員授權，再選 C、D、E 等磁碟或自訂資料夾。只安裝到自己的資料夾時，也可選「僅為我安裝」。支援中文及含空白的路徑。

適用 Windows 10 1903 以上／Windows 11 x64。建議 8 GB RAM、2 GB 可用空間。寫譜與排譜所需環境已內附，不用另外安裝 Python 或 LilyPond。下載好安裝檔後，安裝與寫譜不需要網路。第一次試聽或產生列印輸出時，可能需要建立字型快取，請稍等。

免安裝版須完整解壓縮；`JianpuStudio.exe`、`_internal` 與 `runtime` 要留在同一資料夾。勿直接從 ZIP 壓縮檔視窗執行。

### 更新

0.2.1 起的安裝版可直接更新：

1. 選「說明 → 檢查更新」，連線查詢本專案的正式版本及更新說明。
2. 按「下載更新」。程式會核對下載大小與 SHA-256；下載時可取消，取消不會變更已安裝的程式。
3. 核對成功後按「關閉並更新」。若樂譜尚未儲存，先依提示處理。
4. 安裝程式沿用原安裝模式及資料夾，保留設定與自己的樂譜，更新完成後重新開啟。Program Files 等位置需要 Windows 管理員授權。

0.1.2 或更早版本，請先儲存並關閉程式，再執行新版安裝檔，選相同模式與原資料夾。不用先解除安裝，這次升級後就能使用程式內更新。免安裝版可查詢新版，但需從下載頁下載並完整解壓縮新版。

### 確認目前版本

視窗標題列會顯示「曲名 — 簡譜工房 0.3.1」，右下角固定顯示「版本 0.3.1」；也可選「說明 → 關於」查看。這是正在執行的版本；回報問題時請附版本號。

### 認識畫面：同一張譜可讀也可改

中央是一張按小節排列的簡譜，可閱讀，也可直接點音符選取、輸入或修改。上方「樂譜設定」常駐顯示曲名、來源、調號、拍號、速度、歌詞與紙張設定，不需要展開；譜面頁首仍顯示樂曲資訊。

左側分成「音符工具」與「小節工具」。音符區有新增、修改、填寫三種模式按鈕，以及數字、音高、時值、八度、升降、附點、剪貼與三連音；小節區集中新增、重複、清空與刪除。音符工具底部有三個記號按鈕：「力度 / 演奏」「連線 / 反覆」「倚音 / 二胡」。開啟既有 `.jps` 或範例時預設「修改音符」；新建空譜先使用「新增音符」。

平常直接在主譜面讀寫。開啟或編輯樂譜不會先產生 PDF；要列印或輸出 PDF 時，再從「匯出 / 列印」操作。小視窗可捲動編輯區。本版沒有進階語法編輯區，也維持移除照片辨識與原圖對照入口。

主譜面是可編輯的樂譜顯示；需要列印時才產生的 PDF 是正式輸出。兩者的分頁、換行與符號位置可能不同，PDF 本身不能直接編輯。左側「小節工具」的縮放百分比只調整編輯畫面大小，列印字體請用「樂譜設定 → 紙張與排版」，或列印預覽裡的「紙張設定」。

## 寫一首簡單樂曲

1. 按「新建」，直接在上方常駐的「樂譜設定」填曲名、來源、調號、拍號與速度。
2. 在左側「小節工具」按「＋新增小節」加一個空白小節，程式會自動切到「填寫小節」。要先準備整首曲子的空位，可從小節選單一次新增多個。
3. 將時值選為四分音符，點要填寫的休止符，用滑鼠點 `1–7` 或在譜面按數字鍵。4/4 拍輸入 `1 2 3 4`，就完成一小節；`0` 輸入休止符。
4. 要修改，按左側「修改音符」，在同一張譜面點選音符，再用「音符工具」調整音高、時值、八度、升降或附點，改動會直接套用。
5. 要增加樂段，先選好小節，再按「＋新增小節」或使用小節選單；新小節會有完整拍數的休止符可供填寫。
6. 按 `Ctrl+S` 儲存 `.jps` 專案，下次用「開啟」繼續編輯。

### 三種輸入方式

| 模式 | 適合的操作 | 對後面音樂的影響 |
| --- | --- | --- |
| 填寫小節 | 在休止符空位寫入下一個音符；新增或清空小節後會自動使用 | 消耗可用休止時值，保留後面小節的位置，不覆蓋已寫好的音符；空間不夠會提示 |
| 新增音符 | 逐音建立樂譜，可選「插在選取後」「插在選取前」或「加到曲尾」 | 插入音符會增加時值，後面音符會往後移並重新分小節 |
| 修改音符 | 改所選音符的音高、時值、八度、升降、附點或記號 | 改音高不影響節奏；改時值仍會重新分小節，並非固定小節內的節奏改寫 |

填寫只能使用同一小節內的連續休止空位，不能跨過已寫好的音符。切換回填寫時，直接按左側「填寫小節」。

「填寫小節」及「新增音符」的音符工具設定用於下一個音符；「修改音符」才會直接套用到選取內容。填寫時先選休止符，若該處沒有足夠空位，可縮短下一音符、清空要重寫的小節，或新增小節。

逐音新增後，最後一小節不足時可按「補齊休止符」。提示音符超出小節時，按「定位問題」檢查並縮短時值；跨小節長音可拆成相同音高的音符，再加延音線。

以四分音符為一拍，八分音符是半拍、十六分是四分之一拍。八分音符下方有一條減時線、十六分有兩條、三十二分有三條；高八度的點在上方，低八度在下方。6/8 拍每小節合計六個八分音符，也就是三個四分音符的長度。

歌詞可填在上方「樂譜設定」的「歌詞」欄；二胡純器樂可留白。勾選「五線譜對照」會在正式排版中一併顯示五線譜。

## 新增、清空、刪除與重複小節

先點小節號或小節中的空白處，選取整個小節；也可選該小節內的音符後按 `M`。需要一段小節時，用 `Shift` 連選。小節工具依目前選取範圍操作；右鍵選單也有入口。

| 操作 | 結果 |
| --- | --- |
| ＋新增小節 | 在所選小節之後插入一個空白小節 |
| 前插／曲尾新增 | 從小節選單選擇在所選之前插入，或加在整首曲子的最後 |
| 新增多個小節… | 按「＋新增小節」旁的箭頭，再選「新增多個小節…」，指定數量及插入位置 |
| 清空小節 | 移除選定小節的內容，換成相同小節長度的休止符；節數及後面小節的位置保留 |
| 刪除小節 | 移除選定的小節，後面小節往前移，整首樂曲縮短 |
| 重複小節 | 將完整的所選小節範圍複製一份，插在該段之後 |

例如原有第 1–4 小節：清空第 2 小節後，第 3 小節仍是第 3 小節；刪除第 2 小節後，原第 3 小節會成為第 2 小節。只想重寫旋律時用「清空小節」，想縮短樂曲時才用「刪除小節」。

若最後一小節尚未寫滿，從曲尾新增、重複包含尾節的範圍，會先補足尾節；清空尾節也會留下完整小節的休止符。重複小節需選連續範圍；原譜若有跨小節音符或不完整連線／反覆，請先依提示修正，再使用小節工具。

新增與清空後會自動切到「填寫小節」，可直接填入休止空位。所有小節操作都可用 `Ctrl+Z` 復原、`Ctrl+Y` 重做，包含選取範圍。若改動切斷連弓、延音或反覆，程式會清理受影響的成對記號並提示；未受影響的記號會保留。復原也會還原記號。

## 選取、複製與一起修改

- 點一下選取單一音符；按住 `Shift` 再點另一個音符可連選一段，按住 `Ctrl` 點選可加入或取消個別音符。
- 在音符區按 `Ctrl+A` 全選，按 `Esc` 取消選取；按 `M` 選取目前音符所在的小節，或點小節號／空白處。
- 切到「修改音符」後，多個音符的屬性不一致時會顯示「不同」，附點會顯示混合狀態。只改時值，就只改時值，各音符原本的音高、八度及其他屬性會保留。
- 按 `Ctrl+C` 複製，`Ctrl+X` 剪下，`Ctrl+V` 貼上；貼上依目前的「插在選取前／後／曲尾」位置放入。要調整貼上位置，先切回「新增音符」。
- 按 `Ctrl+D` 重複所選音符，也會依插入位置放入。複製或重複會保留音符上的演奏記號；連線或反覆須連同完整範圍選取，貼上後再檢查。
- 按 `Delete` 刪除；`Ctrl+Z` 復原，`Ctrl+Y` 重做，會一併還原當時的選取範圍。

音符貼上目前接受本程式複製的音符。一般文字不能直接貼成音符，本版沒有原始碼編輯區。小節跳轉可使用左側「小節工具」的「跳到小節」欄，或在音符區按 `Alt+← / →`。

## 常用記號支援範圍

下表是單旋律與二胡常用記號的代表清單，並非所有簡譜符號。可用項目都從圖形介面設定、存入專案並輸出；本版沒有文字語法編輯入口。

| 記號 | 0.3.1 支援與限制 |
| --- | --- |
| 調號、拍號、速度與小節線 | 在上方「樂譜設定」調整全曲；小節線依拍數排列，中途變調／變拍尚無工具 |
| 音高、休止與八度點 | 0–7；上下各兩個八度 |
| 時值、減時線、附點 | 全音符至三十二分音符、單附點；減時線依時值自動顯示 |
| 長音橫線 | 二分、全音符等長時值自動畫出；不是保持音記號 |
| 升、降、還原 | 音符工具直接選擇；還原取消原升降，正式排譜在需要時印還原號，不強制重複提示 |
| 連音／連弓線 | 連續兩音以上，可不同音高；表示連貫或連弓，不合併各音拍數 |
| 同音延音線 | 連接相同音高、八度與升降的相鄰音符，表示同一聲音持續 |
| 延長記號 𝄐 | 在「力度 / 演奏」設定；自由延長，不增加固定小節拍數 |
| 三連音 | 將一個音符或休止拆成三等份，保留總拍數；限未附點二分至十六分音符，不跨小節 |
| 固定力度 | ppp、pp、p、mp、mf、f、ff、fff、sfz |
| 漸強／漸弱線 | 連選兩音以上設定，有起點與終點，不重疊 |
| 演奏記號 | 跳音、保持音、重音、延長、顫音、波音、換氣、迴音、強重音、極短奏、泛音；每音一種 |
| 二胡指法、弓法與滑音 | 空弦及 1–4 指、推／拉弓、上／下滑音 |
| 前／後倚音 | 在主音的記號視窗填 1–8 個小音符，不增加拍數；後倚音與部分主音記號不能並用，限制見下節 |
| 普通反覆 | 選完整連續小節，加反覆起終點；不重疊 |
| 一二房、弱起、多聲部 | 本版尚未支援，不能用進階語法新增；一般反覆不等於一二房 |

長音橫線、同音延音線、連音線與延長記號用途不同。例如以四分音符為一拍，`1 -` 是兩拍長音；用延音線連起兩個四分 `1`，也是同一聲音持續兩拍；連音線可以連 `1 2 3`，各音仍有自己的時值；延長記號則請演奏者依樂曲延長，不能拿來補足缺少的拍數。

## 記號、三連音與二胡奏法

按「修改音符」，在譜面選好音符，再按左側音符工具底部的「力度 / 演奏」「連線 / 反覆」或「倚音 / 二胡」，開啟相應記號頁。選好要改的項目再按確定；其他項目選「保持原樣」，可保留多個音符原本的差異。「無」會移除該項記號。

左側音符工具有三連音入口；上方「記號」選單也可快速加入三連音、連音／連弓線、同音延音線、延長記號及漸強弱。

### 三連音：先選一音，拆成三份

1. 選一個未附點的二分、四分、八分或十六分音符，也可以選休止符。
2. 按左側音符工具的「三連音」，或選「記號 → 拆成三連音（總拍數不變）」；原音會變成三個等時值音符，合計拍數不變，後面小節不會移動。
3. 程式切到「修改音符」。逐一點選三個音符，再按 `0–7` 改音高；組內可以有休止符。
4. 想取消時，選組內音符，按「三連音」旁箭頭選「合併三連音」，或用記號選單的「合併三連音為首音」。會保留第一個音的音高及整組總拍數；如組內後兩音有獨立演奏記號，或有不能合併的連線端點，需先依提示移除，避免合併遺失。

例如把一拍的四分音符拆成三連音，會得到三個八分音符樣式，上方標 3，合計仍是一拍。這是 3:2 節奏，並非三個普通八分音符的一拍半。每組需在同一小節內，不能附點；改時值時要保留三音等長。複製、剪下、刪除或重複時，請選完整三音；音高與演奏記號可以逐音修改。拆分與合併皆可復原。

### 連線、漸強弱與反覆

用 `Shift` 連選所需範圍，再從「記號」選單加入，或直接按「連線 / 反覆」設定：

- 連音／連弓線：至少兩個連續音符，表示連貫或同一弓演奏。
- 同音延音線：至少兩個連續、相同音高的音符；八度及升降後的音高也須相同。
- 漸強／漸弱：至少兩個連續音符。固定力度可放起點與終點，放在中間會提示先拆成兩段。
- 反覆段落：選連續的完整小節，再選「加入所選範圍」。這是普通反覆，沒有一二房視覺工具。

在相應項目選「移除相交的整條記號」，會清除碰到選取範圍的整條連線或反覆，包括範圍外的另一端，避免留下孤立端點；可用 `Ctrl+Z` 復原。同類連弓線、漸強弱或反覆不能重疊。連弓與漸強弱可在一音結束後接下一段。

### 倚音、指法、弓法與演奏記號

選主音後，按「倚音 / 二胡」。前倚音或後倚音欄可連寫 1–8 個 `1–7`，例如 `23`；`#`、`b` 放音高前，`'`、`,` 放音高後表示高／低八度，最多各兩個同向八度符號，例如 `#4'5` 或 `2,,3`。留空表示保持原樣，輸入 `-` 移除。倚音依附主音，不另外增加小節拍數；點倚音也會選到所屬主音；要改倚音請再開此視窗。

**後倚音有組合限制：**同一主音上不能同時有指法、弓法、力度、演奏記號（換氣除外）、連音／連弓線或漸強弱線的端點，以及接向下一音的延音線。這類組合會被拒絕，原譜保持不變。前倚音沒有這項組合限制；後倚音仍可單獨使用，或與三連音、滑音、普通反覆、換氣及漸強弱的中間音並用。

同頁可選空弦 0、1–4 指、推弓 ∨、拉弓 Π，以及上／下滑音。「力度 / 演奏」頁可選 ppp 至 fff、sfz，及支援表中的演奏記號。除上述後倚音限制外，每個音符可同時有指法、弓法、力度等不同類別，但「演奏記號」一次保留一種。

在「新增音符」或「填寫小節」模式開啟記號按鈕，會設定下一個音符的記號；連線與反覆請在修改模式選範圍後設定。指法、弓法、滑音、連音／延音線與倚音不適用於休止符；把音符改成休止符時會清除這些記號；若會破壞既有連線，程式會保留原譜，請先移除該線再修改。

這些記號可顯示於主譜面與列印輸出；正式輸出仍請用列印預覽檢查。試聽使用 Windows MIDI 合成器，音色取決於系統，不能保證逐一重現所有演奏記號，也無法重現真實二胡的弓法、指法與滑音。

| `Enter` | 試聽／停止 |
| `Q / W / E / R / A / S` | 全／二分／四分／八分／十六分／三十二分音符 |

| `[ / ]` | 縮短／延長時值 |
| `.` | 切換附點 |
| `Shift` 點選／`Ctrl` 點選 | 連選／加選音符 |
| `Ctrl+A`／`Esc` | 全選／取消選取 |
| `M` | 選取目前小節 |

## 試聽、PDF 與列印

### 平常讀寫不用 PDF

主譜面會隨編輯立即更新，直接在上面閱讀、點選與修改即可。開啟、輸入或修改樂譜不會在背景先產生 PDF。小節拍數或記號有問題時，譜面會提示，先修正再試聽或輸出。

### 試聽

按上方「試聽」或在譜面按 `Enter`，再按一次停止。程式會準備目前樂譜的 MIDI 再播放，不需要先產生或開啟 PDF；編輯音符會停止舊的試聽。

### 紙張與大小

在上方「樂譜設定」按「紙張與排版」，或在列印預覽按「紙張設定」，可選 A4 或 Letter，譜字大小可調 16–30，每行小節數可選自動或 1–8。紙張與譜字大小會用於正式 PDF；固定每行小節數用於本版可編輯樂譜的輸出。

編輯區的 75%–200% 縮放只影響畫面顯示，不改變列印尺寸。

### 列印預覽與匯出 PDF

1. 要確認列印效果，選「匯出 / 列印 → 列印預覽」或按 `F5`，程式才產生正式 PDF。
2. 在預覽中檢查換行、分頁與記號，可縮放及閱讀多頁；看完按「返回樂譜」繼續編輯。
3. 要保存 PDF，直接選「匯出 / 列印 → PDF 樂譜」。程式會準備最新排版並讓您選位置保存，不必先按 F5。
4. 要列印，選「匯出 / 列印 → 開啟 PDF / 列印」，或在預覽內按「開啟列印」，由 Windows 預設 PDF 閱讀器開啟，再使用閱讀器的列印功能。預覽內也可按「匯出 PDF」保存。

「匯出 / 列印」也可保存 MIDI；本版不提供簡譜文字或 LilyPond 原始碼匯出。正式 PDF 使用目前樂譜內容；主譜面與 PDF 的分頁、換行可能不同，列印前請用預覽確認。

## 照片辨識功能調整

0.3.0 暫時移除照片辨識、原圖對照、Audiveris 校對工具及辨識結果匯出入口，日常介面先專注寫譜。這些功能不是本版可操作的流程；舊版 0.2.1 的照片操作請參考[舊版手冊](https://github.com/miles990/jianpu-studio/blob/v0.2.1/docs/user-guide.md)。一般 MusicXML／MXL 檔案仍可匯入。

回報寫譜或輸出問題時，可選「工具 → 作業訊息」，按「複製完整紀錄」，並附上「說明 → 關於」顯示的版本號。

## 開啟舊專案與匯入樂譜

### 開啟既有專案

用「開啟」選 `.jps`，即可繼續編輯本程式保存的視覺樂譜。本版不再提供 `.jly`／`.txt` 開啟或直接編輯，也沒有「進階語法」切換。

舊版文字模式專案若保留了相同內容的視覺樂譜，且文字沒有另外修改，可自動開啟為可編輯樂譜。若文字內容與視覺樂譜不同，程式會拒絕開啟並說明原因，**不覆蓋原檔，也不替換目前樂譜**。需要處理這類舊專案時，可使用[舊版 0.3.0](https://github.com/miles990/jianpu-studio/releases/tag/v0.3.0)；請保留原檔，不要將不完整的草稿當成相同內容。

### 匯入 MusicXML／MXL

選「檔案 → 匯入 MusicXML」。程式只接受可以完整表示為本版單旋律樂譜的內容；匯入後仍請核對音高、節奏與調號。

匯入範圍比手動寫譜窄：多聲部、和弦、弱起，以及含歌詞、連線、反覆、倚音或三連音等內容，目前都會提示不支援，保留原檔及目前樂譜，不會再導入文字模式。不能直接開啟 EOPN；若其他軟體可匯出 MusicXML，可先匯出後嘗試匯入，但不保證所有記號都可接受。

一二房、弱起、多聲部及中途變調／變拍尚無完整圖形工具。本版不能透過進階語法新增這些內容，請依實際支援範圍使用。

## 儲存與復原

`.jps` 是可繼續編輯的專案；PDF 適合列印與分享，MIDI 適合播放。請用「儲存」保留專案，不要只匯出 PDF。

程式每 15 秒在本機使用者資料夾建立復原暫存；意外中斷後，下次啟動會詢問是否復原。它不是歷史版本備份，重要作品請定期另存及備份。開啟其他專案、離開或套用更新前，未儲存變更會先詢問。

遇到無法轉為可編輯樂譜的舊版復原暫存，程式會先完整備份並顯示保存位置。若備份失敗或暫存無法讀取，會保留原暫存並暫停本次自動暫存；請依提示手動儲存新樂譜。

請一次開啟一個程式實例，避免兩個視窗覆蓋同一份復原檔。

## 常見問題

| 情況 | 處理 |
| --- | --- |
| 按數字鍵沒有輸入音符 | 先點譜面；確認目前是填寫、新增或修改模式。曲名與歌詞欄位會接收文字輸入。 |
| 調整時值卻沒改到已選音符 | 切到「修改音符」。新增與填寫模式只設定下一個音符。 |
| 填寫時提示休止空間不足 | 選休止符，縮短下一音符，或先清空／新增小節；填寫模式不會擠動後面小節或覆蓋已寫好的音符。 |
| 想在 PDF 上改音符 | 返回「編輯樂譜」點選音符；列印預覽中的 PDF 唯讀。 |
| 想看列印結果 | 按 F5 或「匯出 / 列印 → 列印預覽」。PDF 按需產生，平常讀寫不需要開啟。 |
| PDF 無法產生 | 確認小節拍數及連線／反覆完整，選「工具 → 作業訊息」查看原因後重試。 |
| 舊文字模式專案或 MusicXML 無法開啟 | 內容無法完整轉成可編輯樂譜時會被拒絕，原檔及目前樂譜保留；詳見舊專案與匯入說明。 |
| 找不到照片辨識 | 0.3.0 暫時移除照片相關入口；此版先專注寫譜。 |
| 不能試聽 | 等音樂準備完成，確認 Windows 音訊裝置可用；亦可匯出 MIDI，不需要先產生 PDF。 |
| 更新下載失敗 | 確認網路及磁碟空間，重新檢查；也可從官方下載頁取得安裝檔。 |
| 安裝錯誤 5：存取被拒 | 取消並重開安裝，選「僅為我安裝」及預設個人路徑；安裝到 Program Files 請選「為所有使用者安裝」。 |
| 找不到排譜工具 | 重裝完整安裝版；免安裝版請確認完整解壓縮，沒有移走 runtime 等資料夾。 |
| 安裝檔顯示未知發行者 | 目前安裝檔尚未簽章；確認來自官方下載頁，可用 SHA256SUMS.txt 核對。 |
| 想移除程式 | Windows 設定 → 應用程式 → 簡譜工房 → 解除安裝；自己的樂譜不會被刪除。 |

到[問題回報](https://github.com/miles990/jianpu-studio/issues)附上 Windows 版本、程式版本、操作步驟及完整紀錄。照片或樂譜含私人內容時，請先製作可以公開的重現範例。
