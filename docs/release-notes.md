簡譜工房 0.1.3 — 程式內更新

下載 **JianpuStudio-0.1.3-Windows-x64-Setup.exe**。0.1.2 或更早版本請先關閉程式，用此安裝檔升級到原資料夾，不需先解除安裝。

從本版開始，未來可直接使用「說明 → 檢查更新」：

1. 檢查 GitHub 正式版本，查看更新說明。
2. 下載並核對檔案大小與 SHA-256；可取消。
3. 按「關閉並更新」，確認未儲存樂譜，沿用原安裝位置與模式升級。
4. 更新完成後重新開啟程式。

會保留設定與自己的樂譜。Program Files 等位置需要 Windows 管理員授權。免安裝版可查詢更新，仍需從下載頁完整下載解壓縮。

保留 0.1.2 的低解析度照片自動重試、中文診斷與小視窗改善。完整小節式 UI 重設計仍在 0.2 開發中。

適用 Windows 10 1903 以上／Windows 11 x64；所有環境已內附。安裝檔尚未簽章，請從本專案 Release 下載並核對 SHA256SUMS.txt。
