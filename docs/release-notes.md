# 簡譜工房 0.3.0 更新說明

[官方下載頁](https://github.com/miles990/jianpu-studio/releases/latest)：安裝版檔名為 `JianpuStudio-0.3.0-Windows-x64-Setup.exe`，另有免安裝 ZIP 與 SHA-256 核對檔。

## 這版有什麼改變？

- 曲名、作曲者、調號、拍號與速度集中到預設收起的「樂曲設定」，讓小視窗一開啟就能看到譜面。
- 預設「編輯樂譜」：在同一張可閱讀的簡譜上點選、輸入與修改。照片辨識、原圖對照及相關匯出入口先移除，介面專注寫譜。
- PDF 改成按需產生：開啟及編輯樂譜不先排 PDF；需要列印或輸出時才產生。F5 開啟列印預覽，直接匯出 PDF 會準備最新排版後保存。試聽單獨準備 MIDI，不需先產生 PDF。
- 點小節號或小節空白處即可選整節。按「＋新增小節」在所選後新增一節，選單也可前插、加到曲尾或一次指定多節。
- 分開「清空小節」與「刪除小節」：清空留下原長度的休止符；刪除才移除整節、讓後段前移。也能重複一段完整小節。
- 新增「填寫小節」模式。新增或清空小節後可直接用數字鍵填寫休止空位，保留後面小節的位置，不覆蓋已寫好的音符；空間不夠時會提示。
- 小節操作支援復原／重做及選取還原；若操作切斷連弓、延音或反覆，會整理受影響記號並提示。
- 小節快捷鍵：`Insert` 前插一節、`Ctrl+Insert` 一次新增多節、`Ctrl+B` 曲尾新增一節、`Ctrl+Delete` 刪除所選小節。
- 「記號 / 二胡」分頁整理力度／演奏、連線／反覆、倚音／二胡。加入漸強弱線、還原選項、ppp／fff、換氣、迴音、強重音、極短奏與泛音。
- 一音可拆成三連音，合計拍數不變；也可合併回首音。前／後倚音可直接設定，連音線、同音延音線與延長記號使用不同名稱與入口。
- 標題列與右下角固定顯示執行版本，也可從「說明 → 關於」確認。

## 什麼時候需要 PDF？

平常在主譜面閱讀及編輯即可。要確認列印結果時，選「匯出 / 列印 → 列印預覽」或按 F5；需要保存 PDF 時直接匯出。預覽可返回編輯樂譜，PDF 本身仍不能直接修改。主譜面的分頁、換行與符號位置不保證和正式 PDF 完全一致。

原本的「新增音符」「修改音符」保留；新增音符與修改時值仍可能讓後面音符重新分小節。若要在既有空白小節內寫譜並保留後段位置，請使用「填寫小節」。

## 如何更新至 0.3.0？

**0.2.1 起的安裝版：**「說明 → 檢查更新 → 下載更新」，檔案大小與 SHA-256 核對成功後按「關閉並更新」。依提示儲存樂譜，沿用原安裝模式及位置，完成後重新開啟。

**0.1.2 或更早：**先儲存並關閉程式，再執行本版安裝檔，選原安裝模式與資料夾。不需先解除安裝，之後即可從程式內更新。

設定與自己的 `.jps` 樂譜會保留。Program Files 等位置需要管理員授權。免安裝版可檢查新版，仍需從下載頁下載並完整解壓縮。

## 使用前請留意

照片辨識的底層程式保留，但 0.3.0 不提供照片相關操作入口；一般 MusicXML／MXL 匯入仍保留。

後倚音與同一主音的指法、弓法、力度、多數演奏記號或部分連線端點尚不能並用。程式會提示並保留原譜；前倚音沒有這項組合限制，細節見手冊。

快捷鍵沿用部分 EOP 習慣，不能直接開啟 EOPN。弱起、一二房、多聲部仍需進階語法，尚無完整圖形化流程；進階原始碼不會自動轉回視覺音符。試聽使用 Windows MIDI 音色，無法重現真實二胡弓法與滑音。

適用 Windows 10 1903 以上／Windows 11 x64。安裝檔尚未簽章，請從本專案下載頁取得並可核對 `SHA256SUMS.txt`。操作方式見[完整手冊](https://github.com/miles990/jianpu-studio/blob/main/docs/user-guide.md)。
