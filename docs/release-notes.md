簡譜工房 0.1.2 — 照片自動處理與使用體驗修正版

**下載 JianpuStudio-0.1.2-Windows-x64-Setup.exe**。所需環境全部內附，不用另外安裝 Python、Java 或排譜工具。

- 低解析度五線譜若因譜線間距太小而被拒絕，會依實際間距自動放大並重試一次。保留原圖，並限制放大後大小。
- 辨識失敗先顯示中文原因；新增完整紀錄複製，方便排查問題。
- 照片調整使用縮圖預覽並合併連續變更，正式辨識仍使用完整影像。
- 小視窗會收起左側導覽，編輯區可捲動；主要功能可從上方選單操作。
- README 改為給一般使用者看的安裝、寫譜、照片辨識與列印說明。

已安裝 0.1.0／0.1.1：先儲存樂譜並關閉程式，再執行新版安裝檔，選原安裝模式與原資料夾即可。不需先解除安裝。0.1.2 尚未內建自動更新。

照片辨識適用印刷五線譜，不支援手寫或數字簡譜影像。自動放大無法補回模糊或遺失細節，辨識後仍須校對。複雜譜面可能進入進階語法模式。

適用 Windows 10 1903 以上／Windows 11 x64。安裝檔未簽章，請從本 Release 下載並核對 SHA256SUMS.txt。完整 UI 重整與二胡圖形化記號會於後續版本提供。
