# 簡譜工房 0.3.1 更新說明

[0.3.1 官方下載頁](https://github.com/miles990/jianpu-studio/releases/tag/v0.3.1)：安裝版檔名為 `JianpuStudio-0.3.1-Windows-x64-Setup.exe`，另有免安裝 ZIP 與 SHA-256 核對檔。

## 這版有什麼改變？

- 「樂譜設定」常駐上方，曲名、來源、調號、拍號、速度、歌詞與紙張設定直接可見，不再需要展開。
- 左側分成「音符工具」與「小節工具」。新增、修改、填寫改為直接按鈕；音高、時值、八度、升降、附點及剪貼工具集中在一起。
- 音符工具底部的「力度 / 演奏」「連線 / 反覆」「倚音 / 二胡」各有直接入口，按一下就開對應設定。
- 移除進階語法與原始碼開啟／匯出入口，日常只在同一張可編輯簡譜上操作。匯出保留 PDF、MIDI 與列印。
- 舊文字模式專案與 MusicXML 只有能完整表示為可編輯樂譜時才載入。無法完整處理時會提示，保留原檔與目前樂譜，不悄悄只留下部分內容。

小節新增、填寫、清空、刪除、重複及復原保留；PDF 仍只在列印預覽或匯出時產生，試聽獨立準備 MIDI。

## 舊樂譜與功能限制

一般 `.jps` 視覺樂譜可繼續編輯。舊文字模式專案若文字未另行改動、且與保存的視覺樂譜相同，可自動載入；內容不一致時拒絕開啟，可保留原檔並使用 0.3.0 處理。本版不再開啟 `.jly`／`.txt`。無法載入的舊版復原暫存會先完整備份；備份失敗或暫存無法讀取時保留原檔，暫停自動暫存並提示手動儲存。

弱起、一二房、多聲部尚無完整圖形工具，本版也不能透過進階語法新增。複雜 MusicXML 可能被拒絕；不能直接開啟 EOPN。這次改善操作分組，不代表所有簡譜記號都已完成。

後倚音與同一主音的指法、弓法、力度、多數演奏記號或部分連線端點仍不能並用；程式會提示並保留原譜，細節見手冊。照片辨識與原圖對照入口維持暫時移除。試聽使用 Windows MIDI，不能重現所有二胡演奏細節。

## 如何更新至 0.3.1？

0.2.1 起的安裝版可選「說明 → 檢查更新 → 下載更新」，檔案大小與 SHA-256 核對成功後按「關閉並更新」。依提示儲存樂譜，沿用原安裝模式與位置，保留設定及自己的專案。Program Files 等位置需要管理員授權。

0.1.2 或更早請儲存並關閉程式，再執行新版安裝檔，選原模式及資料夾，不需先解除安裝。免安裝版需下載並完整解壓縮新版。

適用 Windows 10 1903 以上／Windows 11 x64。操作與記號支援範圍見[完整手冊](user-guide.md)。
