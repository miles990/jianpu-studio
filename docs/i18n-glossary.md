# 介面語言與用語對照（zh_TW → zh_CN）

繁體中文是來源語言：程式碼寫 `tr("繁體原文")`，簡體對照表在 `src/jianpu_studio/i18n_zh_cn.py`。
簡體由 OpenCC 起草後逐句人工審過，用大陸電腦與音樂用語，不是單純轉字。
OpenCC 只是開發時的工具，不是執行時相依；測試用它檢查簡體對照表有沒有殘留繁體專用字。

## 規則

- 每個 `tr()` / `N_()` 的字串都必須有簡體條目，沒有被用到的條目也不能留著（`tests/test_i18n.py`）。
- 簡體譯文不可重複，也不可等於另一條繁體原文，這樣切回繁體時才能無歧義地還原畫面上已顯示的文字。
- 使用者輸入的內容（曲名、作曲者、歌詞）永遠不轉換。
- 專有名稱：簡譜工房 / 简谱工房；MusicXML、LilyPond、MIDI、PDF 不翻。

## 不確定、請母語使用者確認

- 專案 → 项目：一般使用者較熟悉；音樂軟體另有「工程」的說法。
- 極短奏（對話框）→ 极短音，極短斷奏（譜面無障礙文字）→ 极短跳音：繁體兩處用字不同，簡體需要互不相同才能還原。
- 曲尾 → 曲末：也可用「乐曲末尾」。
- 連線 vs 連音線：頁籤與選單用泛稱「连线」，記號名稱用「连音线／延音线」。
