# 計畫（0.4.0）— 策略與規劃合併

來源：使用者 2026-11-27 指示＋五張照片（EOP 四個工具面板、〈月夜愁〉二部譜）＋ issue #1（jpword 民樂演奏符號）。
交付模式：成品。基準：現有 0.3.1（Windows、繁中、單旋律）。

## 核心賭注
「一張可直接點選的譜面＋一個找得到任何記號的面板」：選音符 → 搜尋或點記號 → 譜面立刻出現，印出來一樣。

## 目標使用者
- 一般使用者（熟 EOP 的二胡愛好者，Windows／Mac，繁中或簡中）。
- 進階製譜者（要民樂技法、反覆記號、二部譜）。

## 範圍（S-n，全部是指定需求）
- S1 介面語言：繁中／簡中，可在程式內切換，立即生效且不丟樂譜、復原紀錄；依系統語系自動選；設定會記住。
- S2 平台：Windows x64 與 macOS（Apple Silicon 必做；Intel 便宜就做）。mac 要能寫譜、試聽、出 PDF、開檔關聯、選單與快捷鍵合乎 mac 慣例。
- S3 力度：ppp–fff、sf、fz、sfz、sfzz、fp、sfp、sfpp、rf、rfz、漸強／漸弱（照片 1）。
- S4 小節線：虛線、雙線、終止線、反覆起／訖／雙向、D.C.、D.S.、Segno、To Coda、Coda、Fine、一房／二房／結尾房（照片 2）。
- S5 其他記號：連線、延音線、三連音、8va／8vb、重音、延長、保持、V、accel.、rit.、踏板（照片 3）。
- S6 演奏法：上／下／複波音、tr、tr~~~、震音斜線 1–4、頓音▼▽、琶音上／下、帶升降的波音（照片 4）。
- S7 民樂演奏符號（issue #1）：二胡（內外弦、推拉弓、上下滑／回滑／墊指滑、揉弦、泛音、顫弓、頓弓、拋弓、撥弦、空弦、指法）為主，另含古箏、琵琶、笛子常用組；記號目錄可擴充。
- S8 弱起小節、多聲部（二部譜含大括號，照片 5）。
- S9 介面：專業、好檢視、好操作、好編輯；記號面板可搜尋、有名稱提示、最近使用、未選取時變灰並說明原因；淺色／深色。
- S10 既有保證不退步：舊 .jps 可開、復原／重做、自動復原、更新、安裝路徑、中文路徑。

## 明確不做（本版）
- 照片辨識入口（維持移除）、EOPN 匯入、和弦名（Am）、其他樂器音色、聲部中途才出現（照片 5 前兩行單聲部）列為已知限制候選。
- mac 版簽章與公證（沒有憑證）；mac 更新只開下載頁。

## 驚豔時刻（X → Y）
- W-1 選音符後在面板打「滑」或「hua」→ 立刻列出所有滑音記號，點一下譜面即出現（儀器：≤ 3 步；EOP 需先找對分頁再找圖示）。
- W-2 切換繁／簡 → 整個介面當場換字，樂譜與復原紀錄原封不動（儀器：1 步、0 次重啟）。
- W-3 同一個 .jps 在 Mac 與 Windows 打開，譜面與 PDF 一樣（儀器：雙平台實跑同一檔）。
- W-4 沒被要求的：點記號面板任一格會顯示「印出來長這樣」的小預覽與一句用法；〈月夜愁〉範例一開就能看到二部譜＋Coda。

## 技術決策（探針證據在 work/probes/）
- D1 記號以**單一目錄**（symbols 登記表）驅動：面板、畫布繪製、匯出語法、白名單、兩種語言名稱都從它來。Note 新增多值 `marks`，不再每個記號加一個欄位。
- D2 專案檔 version 2；v1 仍可開並自動升級；新版存檔舊版會拒開（已知）。
- D3 多聲部＝Score.parts；弱起＝Score.pickup；小節線／房／導航記號掛在小節邊界的音符上。匯出走 jianpu-ly 原生語法（NextPart、`4/4,8`、A{ }、DC/DS/Segno/ToCoda/Fine），大括號在 worker 後處理。vendor 不改。
- D4 LilyPond 三平台統一 2.26.0（2.24 沒有 Apple Silicon 版；2.26 移除 set-global-fonts，實測 13 個引擎測試失敗，需改字型語法）。
- D5 mac 試聽用 ctypes 呼叫 AudioToolbox MusicPlayer（實測載入、播放、取時間、停止皆回 0；壞檔回 100002），零額外體積，與 Windows 的 winmm 作法對稱。
- D6 i18n：`tr("繁體原文")` 以繁中為來源字串＋審過的簡中對照表（OpenCC 只用來起草），測試用 AST 檢查每個 tr 字串都有簡中；音樂與電腦用語用大陸慣用詞（小节、保存、导出、打印、撤销、设置）。
- D7 mac 打包：PyInstaller .app（每架構各一）＋ hdiutil DMG，ad-hoc 簽章；README 說明「仍要打開」流程。
- D8 介面：Fusion＋一份設計代幣產生 palette 與 QSS，畫布顏色同源；圖示由 Codex 協助產出（使用者 2026-11-27）。
