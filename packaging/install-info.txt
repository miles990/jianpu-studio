簡譜工房 Jianpu Studio

完整安裝包含：
• 繁體中文簡譜編輯器
• Python 與 Qt 執行環境
• LilyPond 2.24.4 排譜引擎
• Audiveris 5.11.0 五線譜照片辨識引擎、Java 執行環境及英文辨識字庫
• 中文樂譜字型

不需另外安裝 Python、Java，也不需設定 PATH。
安裝完成後，編輯、排譜與照片辨識皆可離線使用。
安裝到目前使用者的資料夾，不需要系統管理員權限。

支援 Windows 10/11 64 位元（x64）。建議至少 8 GB RAM、2 GB 可用磁碟空間。
照片辨識適用清晰的印刷五線譜，不支援手寫或數字簡譜照片；辨識後請校對。
